# Servicios

Cada subdirectorio contiene la documentación y configuración de un servicio
prestado por Desktop 1. Los despliegues son explícitos y los secretos viven
fuera de Git.

Servicios actuales: Alloy, Cockpit, Portainer Agent y Telegraf. `promtail/`
queda como referencia histórica; el agente activo es Alloy.
