# Servicios

Servicios configurados u observados:

- Cockpit: administración nativa.
- Alloy: logs Docker hacia Loki en Lenovo.
- Telegraf: métricas del host y Docker hacia InfluxDB en Lenovo.
- Portainer Agent: administración desde Portainer central.

ML, LLM, transcripción y WhatsApp son responsabilidades futuras del nodo, no
servicios desplegados actualmente.
