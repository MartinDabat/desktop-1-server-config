# Reconstrucción de Desktop 1

La reconstrucción comienza con Debian sin entorno gráfico, SSH, Git, Docker,
Cockpit, Tailscale y observabilidad. No incluye todavía ML, LLM, transcripción,
WhatsApp ni el montaje del segundo disco.

Antes de cada servicio se deben verificar backup, secretos externos, red,
persistencia, rollback y procedimiento de validación.
