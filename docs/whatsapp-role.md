# Rol en analítica de WhatsApp

Desktop 1 es el destino previsto para análisis ML local, LLM pequeño y
transcripción asíncrona de audios. No se ejecutará Baileys como servicio
permanente y no recibirá QR, tokens ni sesiones de la importación histórica
sin una aprobación específica.

Antes de desplegar modelos se deben definir dataset, privacidad, límites de
CPU/RAM, runtime, API, cola y observabilidad en el proyecto común del
HomeLab.
